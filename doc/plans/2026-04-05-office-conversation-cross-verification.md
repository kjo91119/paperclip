# 2026-04-05 Office Conversation Cross Verification

## 범위

이번 변경은 오피스 화면을 `2D 씬 + 대화 패널 + 우측 상태 패널` 구조로 재편하고, 기존 이슈/댓글 모델 위에 아래 흐름을 얹는 작업입니다.

- DM V1: 에이전트별 활성 이슈 스레드를 채팅형으로 렌더링
- 전체회의 V1: 진행자 1명 + 참가자 멘션 기반 회의 이슈 생성
- 2D 오피스 씬 접기/펼치기
- 받은 편지함에서 `/office?...` 딥링크로 바로 대화 열기
- 메시지 전송 전 컨텍스트 요약 표시

## 수동 검증 시나리오

### 1. 오피스 기본 구조

1. `/<companyPrefix>/office`로 들어갑니다.
2. 상단 통계 카드 아래에 `회사 메신저` 배너가 보이는지 확인합니다.
3. 본문이 `2D 오피스`, `대화 패널`, `우측 상태 패널`로 분리되어 보이는지 확인합니다.

반려 기준:

- 여전히 예전 `오피스 메시지 독` 단일 폼 화면처럼 보임
- `대화 패널`이 아예 보이지 않음

### 2. 2D 오피스 접기/펼치기

1. 대화 패널 상단의 `2D 오피스 접기` 버튼을 누릅니다.
2. 2D 씬이 사라지고 대화 패널 폭이 넓어지는지 확인합니다.
3. 다시 `2D 오피스 펼치기`를 눌러 복원되는지 확인합니다.

반려 기준:

- 버튼 라벨만 바뀌고 실제 레이아웃은 바뀌지 않음
- 접은 뒤 다시 펼칠 수 없음

### 3. DM V1 스레드 선택

1. `CEO`, `CTO`, `CMO` 중 하나를 누릅니다.
2. 좌측 카드에 선택한 에이전트와 현재 작업이 보이는지 확인합니다.
3. 가운데 `대화 스레드` 목록이 해당 에이전트의 열린 이슈들만 보여주는지 확인합니다.
4. 스레드를 하나 누르면 우측 상단 헤더와 아래 타임라인이 그 이슈 기준으로 바뀌는지 확인합니다.

확인 포인트:

- 이슈 설명이 첫 버블로 보임
- 이후 댓글이 시간순으로 이어짐
- `이슈 상세` 링크가 정상 동작함

반려 기준:

- 서로 다른 이슈 댓글이 한 타임라인에 섞여 보임
- 이슈 설명이 빠져 첫 메시지가 사라짐

### 4. 전체회의 V1

1. 상단 탭에서 `전체회의`를 선택합니다.
2. 진행자를 1명 고르고, 다른 에이전트를 최소 1명 더 선택합니다.
3. 제목과 본문을 입력하고 `새 회의 이슈 만들기`를 누릅니다.
4. 새 회의 이슈가 회의 목록에 나타나고, 헤더에 진행자/참가자가 보이는지 확인합니다.

확인 포인트:

- 진행자는 실제 assignee 1명으로 유지
- 참가자는 멘션 컨텍스트로만 표시
- 본문에 `회의 형식: 전체회의` 규약이 들어감

반려 기준:

- 진행자를 포함해 2명 미만인데 버튼이 활성화됨
- 회의 생성 후 목록에서 회의 스레드를 찾을 수 없음

### 5. 전송 전 컨텍스트 요약

1. 프로젝트를 고르거나 경로를 입력합니다.
2. 전송 직전 상단 요약 카드에서 아래 값이 보이는지 확인합니다.
   - 방식
   - 대상 또는 진행자
   - 현재 스레드 또는 참가자
   - 프로젝트
   - 경로

반려 기준:

- 옵션을 바꿔도 요약 카드가 갱신되지 않음
- 프로젝트/경로가 실제 전송 대상과 다른데 경고가 없음

### 6. 경로 정규화

1. `C:\Users\...` 형태 경로를 입력합니다.
2. `WSL 복사`를 눌렀을 때 `/mnt/c/...` 형태로 복사되는지 확인합니다.
3. `Windows 복사`를 눌렀을 때 다시 `C:\...` 형태로 복사되는지 확인합니다.
4. 프로젝트를 고른 뒤 `프로젝트 경로 사용`을 눌렀을 때 입력칸이 해당 경로로 바뀌는지 확인합니다.

반려 기준:

- Windows 경로가 그대로 전송 경로처럼 남음
- 프로젝트 변경 후 이전 경로가 남아 stale context가 생김

### 7. 현재 스레드 코멘트 / 새 이슈 생성

1. DM 모드에서 열린 스레드를 고르고 본문을 입력합니다.
2. `현재 작업에 코멘트`를 누릅니다.
3. 같은 스레드 타임라인에 새 메시지가 붙는지 확인합니다.
4. 스레드가 없는 상태에서는 `새 이슈로 보내기`로 새 이슈를 만들고, 새 이슈가 스레드에 선택되는지 확인합니다.

반려 기준:

- 코멘트가 현재 보이는 스레드가 아닌 다른 이슈에 붙음
- 새 이슈 생성 후 여전히 이전 스레드가 선택된 상태로 남음

### 8. 받은 편지함 -> 오피스 딥링크

1. `받은 편지함`에서 agent assignee가 있는 이슈를 찾습니다.
2. 이슈 행 아래 `대화에서 열기` 또는 `회의에서 열기`를 누릅니다.
3. `/<companyPrefix>/office?mode=...&agent=...&issue=...` 형태로 이동하는지 확인합니다.
4. 도착 후 해당 이슈가 바로 선택된 상태인지 확인합니다.

반려 기준:

- 링크가 없는 이슈가 agent-assigned인데도 오피스 바로가기가 보이지 않음
- 링크는 열리지만 다른 스레드가 선택됨
